# Guidelines for AI Agents

This repository is the Tier A IDD experiment for the `daymark` offline
task-planning CLI.

See `AGENTS.md` for shared repository rules and validation commands.

## IDD workflow

Start with [docs/idd-workflow.md](docs/idd-workflow.md), then read
`.github/instructions/idd-overview-core.instructions.md` and the routed
phase file. This experiment uses `mid-llm-test` markers,
`instructions-only` helpers, and a `no-advisory` review profile.
